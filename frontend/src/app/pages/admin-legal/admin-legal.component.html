Aide

Aide au contenu RGPD/CNIL

Cette zone sert de rappel pour structurer correctement ta page légale.

À prévoir dans la page :

  • identité du responsable du site ;
  • hébergeur ;
  • formulaire de contact ;
  • données collectées ;
  • finalité du traitement ;
  • durée de conservation ;
  • droits RGPD ;
  • adresse de contact pour exercer les droits.

Important :

Cette zone ne remplace pas un conseil juridique. Elle permet simplement d’administrer proprement le contenu légal du portfolio.

Le backend nettoie le HTML avec JSoup avant affichage public, mais il faut tout de même éviter de coller du code externe non maîtrisé.

Pensez à enregistrer avant de quitter la page.
